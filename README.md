# Maximiliano Ramon

Personal portfolio: engineering interests, work experience, leadership, golf, travel, and contact information.

Live website: https://maximilianoramon.github.io/

## Website files

This is a static website. The homepage is `index.html`, with styles in `styles.css`, mobile navigation in `script.js`, and photos, fonts, and the downloadable résumé in `assets/`. No package installation or build step is needed.

## Publishing

GitHub Pages publishes the root directory of the `main` branch. Keep **Settings → Pages → Source** set to **Deploy from a branch**, with **main** and **/(root)** selected. The `.nojekyll` file keeps the site as plain HTML, CSS, and JavaScript.

## Editing

- Update page content in `index.html`.
- Update layout and colors in `styles.css`.
- Update mobile navigation in `script.js`.
- Replace photos and the résumé in `assets/` as needed.

The Archivo font is included with its license in `assets/Archivo-LICENSE.txt`.
