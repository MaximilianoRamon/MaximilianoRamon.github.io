# Maximiliano Ramon

Personal portfolio: engineering interests, work experience, leadership, golf, travel, and contact information.

Live website: https://maximilianoramon.github.io/

## Website files

The complete static website is in `dist/`, including the photos, fonts, and downloadable résumé. No package installation or build step is needed.

## Publishing

GitHub Pages deploys `dist/` automatically when the `main` branch changes. The repository's **Settings → Pages → Source** should be set to **GitHub Actions**. The workflow can also be started manually from the Actions tab.

## Editing

- Update page content in `dist/index.html`.
- Update layout and colors in `dist/styles.css`.
- Update mobile navigation in `dist/script.js`.
- Replace photos and the résumé in `dist/assets/` as needed.

The Archivo font is included with its license in `dist/assets/Archivo-LICENSE.txt`.
